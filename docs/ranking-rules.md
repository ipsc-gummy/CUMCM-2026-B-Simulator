# 排行榜规则

Q3 与 Q4 分榜显示。

1. 清除率严格大于 `89.9%` 的成绩进入达标组。
2. 达标组按平均清除时间升序排列。
3. 未达标组整体排在达标组之后。
4. 多局成绩先分别计算每局平均清除时间，再对各局等权平均。
5. 多局展示各局平均清除时间的最小值与最大值。
6. 单局成绩展示该局干扰源数量。
7. 总时间既不公开展示，也不参与排序或同分处理。

`VERIFIED` 表示平台在固定 simulator 版本上完成认证。`OPEN SOURCE VERIFIED` 表示队伍主动同意
公开该次提交源码，且平台在隔离环境重新运行后通过认证。普通 `VERIFIED` 不公开源码。
